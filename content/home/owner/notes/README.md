# Notes

Reading notes are under `humanities/`. Paths use lowercase kebab-case: `a-z`, digits, and hyphens.

```text
humanities/<subject>/<work>/<file>
```

Add a markdown file in this directory, then rebuild.
With a GitHub token, root can also create one from the shell.
