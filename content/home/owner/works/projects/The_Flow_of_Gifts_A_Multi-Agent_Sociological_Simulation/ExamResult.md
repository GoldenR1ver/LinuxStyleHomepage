> 本文档是 [`README.md`](./README.md) 的实验侧配套文档，聚焦两件事：**九个组件的功能**，以及**它们在实验中产生了什么结果、为什么能产生这些结果**。

## 摘要

在 100 人村庄、365 天、DeepSeek 实跑（seed=42）的条件下，本实验复现了阎云翔式的礼物流动格局：

| 结论       | 证据                                             |
| -------- | ---------------------------------------------- |
| 拟真可检验    | 互惠率 0.90、违约率 0.022、平均回礼延迟 ~17 slots，落在"互惠中态"区间 |
| 位→礼而非钱→礼 | 礼物—声望相关 0.51，礼物—财富相关仅 0.07                     |
| 有分层但不极端  | 声望 gini 0.16，Top10 声望礼份额 27%                   |
| 纵向不对称成立  | 干部组收礼 1118、违约 0；体力/服务组收礼 270、违约 0.14           |
| 状态与话语一致  | 344 次对话 0 失败，`alignmentRate = 1.0`、`warn = 0`  |
| 可复现      | seed=42 复跑各项指标方向一致、量级同阶                        |
| 组件有独特作用  | A1–A3、E2–E4 消融各自只打掉对应的社会现象                     |

## 2. 九个组件的功能

九个组件按数据流分层，编号与汇报 PPT、结题报告一致：

```text
触发层  8 事件系统
          ↓
表达层  6 LLM 对话
          ↓
记忆层  5 PET → 4 认知树
          ↓
认知层  3 BDIE + 9 性格派生
          ↓
结算层  1 RuleEngine + 礼单账本
          ↑
       2 关系图 · 7 经济 / 日活力
```

### 2.1 分工总表

| #   | 组件                    | 模拟人类的哪一块     | 为何不可替代                    | 关掉会怎样              |
| --- | --------------------- | ------------ | ------------------------- | ------------------ |
| 1   | **RuleEngine + 礼单账本** | 人情规范与结算      | LLM 不能"声称已改现金"            | 互惠崩溃、账目不可信         |
| 2   | **关系图**               | 社会结构与情感取向    | 纵向轴是 H3 唯一载体              | H3 失效、闲话无靶         |
| 3   | **BDIE**              | 当下身心状态与行动优先级 | 把"手头紧 / 高压 / 欠情临窗"变成可计算驱动 | 社交与回礼变"平均人"        |
| 4   | **认知树**               | 主观记忆与关系叙事    | 不是客观边，而是"我以为我们的关系"        | 对话失语境、单向流动增强       |
| 5   | **PET 个人事件表**         | 近期显著事件记忆     | 比全局日志更贴近"个人记得什么"          | 事件提及与针对性回应变弱       |
| 6   | **LLM 对话系统**          | 自然语言表达与局部态度  | 规则不会说话，话语是过程证据            | 只剩指标，无可演示互动        |
| 7   | **经济系统 / 日活力**        | 生存约束与压力底噪    | 无经济则礼俗变成无限请客游戏            | 礼期望膨胀、分层扭曲         |
| 8   | **事件系统**              | 事务触发         | 决定"何时有事"，与"做什么"解耦         | 时序失真，burstiness 消失 |
| 9   | **性格 / 人格派生**         | 个体异质性        | 把人口统计条件化为异质倾向             | 决策同质化，微观异质性消失      |

### 组件 1 · RuleEngine + 礼单账本

`sim/backend/rules/rule_engine.ts`

**功能**

- 唯一的世界状态写入闸门：`cash`、`ledger`、`face`、`prestige`、`trust` 的每次变更都必须经 `commit()`。
- 礼单状态机：`pending_reply → replied | defaulted | closed`。
- 维护 W4–W10 时间性规则：跨场合抵扣、窗口调制、困难延期、纵向豁免。
- 每次提交写 append-only 日志，带 `before / after / reason / formula`。

**在实验中的作用**

- 保证"内容与决策分离"：LLM 只提案，规则负责承诺与结算，这是可证伪与可回放的基础。
- 回礼窗口是 H4（延迟互惠）的承载者；纵向豁免是 H3（纵向不对称）的承载者。

**证据**

- 全部 365 天状态可由 `event_log.jsonl` 重建，`verify:frontend` 逐 checkpoint 校验通过。
- E2（关互惠规则）后违约上升、互惠下降、延迟趋近 0。

---

### 组件 2 · 关系图

`sim/backend/systems/relationship/`

**功能**

- 有向边（A→B 与 B→A 独立）存 `trust / intimacy / affection / dislike / reciprocityScore / giftDebt`。
- 标注 `relationAxis`（horizontal / vertical_up / vertical_down）与 `socialBasis`（kin / friend / neighbor / colleague）。
- `RelationshipSummarizer` 把边翻译成人话注入对话 Prompt。

**在实验中的作用**

- 纵向轴是 H3 的唯一载体：`vertical_*` 直接使礼物不进债窗。
- `dislike` 决定闲话对象与拒绝对象的选择。
- `giftDebt` 是"关系深度"的可计量代理，也是违约风险的同向指标。

**证据**

- `defaults ↔ giftDebtOut = 0.89`：礼债累积与违约同向。
- E3（仅横向）后进贡不再单向，H3 格局失效。

### 组件 3 · BDIE

`sim/backend/cognition/bdi.ts`

**功能**

- 在 BDI 之上加入 Emotion：`mood / arousal / stress / energy`。
- `syncRepayIntentionsFromLedger`：把逼近窗口的礼债提升为 priority 95–99 的 Intention。
- `applyGiftDefaultToBdi`：违约时按 severity 调整双方情绪与 repair / distance 意图。
- `computeDebtActionBias`：把"欠情"折算成 `repayUrgency`，同时压低 `giftWillingness`。

**在实验中的作用**

- 让决策突破 LLM 默认伦理：同样是喜事，手头紧、压力大、欠情未还的人会推脱或降低金额。
- 提供微观异质性，避免全村变成"平均人"。

**证据**

- 拒绝约 1.3 次/天，非无脑参与。
- `mood ↔ stress = −0.817`：情绪双向传播，而非单向受控。
- A1（无 BDIE）后社交发起、拒绝、回礼紧迫度全部"变平"。

---

### 组件 4 · 认知树

`sim/backend/cognition/cognitive_tree.ts`

**功能**

- 四层结构：`social → circle → relation → dialogue`。
- 对话摘要按 `influenceSum` 累积，超过阈值 15 晋升为 relation 节点。
- 晋升后的节点作为"主观关系记忆"回注后续对话 Prompt。

**在实验中的作用**

- 提供"主客分离"：世界边是客观可结算关系，认知树是"我以为的关系史"。
- 支撑跨事件、长周期的互动连贯性，而不是每轮对话都失忆。

**证据**

- 主跑认知树晋升 50+ 次，对话摘要可持续回注。
- **A2（无认知树）**：个人行为变随机，且地位差异下礼物单向流动显著增强——证明主观记忆对维持互惠对称性有因果作用。

### 组件 5 · PET 个人事件表

`sim/backend/systems/event/pet.ts`

**功能**

- 每个 Agent 维护近期显著事件列表，带 `confidence`。
- `propagate` 按可见性向相关 Agent 传播事件；`applyPetBeliefs` 同步为 Belief（B ← PET）。

**在实验中的作用**

- 决定"这个人记得哪件事"，使事件提及与针对性回应成为可能。
- 比全局日志更接近人类的选择性记忆。

**证据**

- PET 计数在回放面板可逐人查看。
- 话语对齐率 1.0 说明"记得的事"与"说出口的话"一致。

### 组件 6 · LLM 对话系统

`sim/backend/systems/dialogue/`

**功能**

- 三种模式：`dialogue`（双人）、`host`（主持多人）、`random`（群聊）。
- 受 `state_narrative` 约束：高压、缺钱、内向、欠情未还都会写进 Prompt。
- 明确禁止声称修改世界状态；输出为 JSON（话语 + 情感 + 礼貌 + 提及事件）。

**在实验中的作用**

- 话语是过程证据：不仅看指标，还能看"他为什么这样说"。
- 说与做受同一套状态约束，避免"嘴上请客、账上没钱"的割裂。

**证据**

- 主跑 344 次对话，0 失败，`alignmentRate = 1.0`、`warn = 0`。
- 高压个体未系统性出现"请客做东"话语。

---

### 组件 7 · 经济系统 / 日活力

`sim/backend/systems/economy/`、`systems/person/daily_vitals.ts`

**功能**

- 日生活成本 20–90 元，按职业、地位与 `essentialExpenseRatio` 计算。
- 月工资结算、存款与负债、现金与信用上限。
- 礼期望膨胀检查，限制单笔礼金相对现金的比例。

**在实验中的作用**

- 提供生存约束与压力底噪：没有经济约束，礼俗会退化成无限请客游戏。
- `economyAffordFactor` 把"有没有钱"变成"能不能回礼"：现金充足 ×1.15，现金 < 收入 8% ×0.25。

**证据**

- 干部组违约 0、体力/服务组违约 0.14——违约有社会梯度。
- **A3（无限资金）**：礼期望膨胀、分层扭曲，经济约束假说被破坏。

---

### 组件 8 · 事件系统

`sim/backend/systems/event/`

**功能**

- 三类驱动：
  - **公共事务**（scheduled）：婚礼、葬礼、道路养护、卫生宣传等。
  - **社交驱动**（`social_drive`）：闲谈、串门、闲话，由性格与情绪决定发起概率与对象。
  - **回礼驱动**（`repay_drive`）：从礼债生成回礼事件，按概率尝试。
- `pairScore` 综合关系质量、声望拉力与压力寻求；`initiatorProbability` 由性格与情绪调制。

**在实验中的作用**

- 决定"何时有事、谁和谁互动"，与 LLM"做什么"完全解耦。
- 时序真实性：避免同步 slot 退化成均匀的泊松过程。

**证据**

- 主跑完成大量公共事务与 92 次闲话，`dislike ≥ 35` 的边 7 条。
- 干部组网络度数 16.1、体力组 15.2——互动分布本身带地位差异。

### 组件 9 · 性格 / 人格派生

`sim/backend/cognition/personality.ts`

**功能**

从 BigFive 派生三个行为倾向：

```text
introversion = 1 − E
pickiness    = 0.45(1 − A) + 0.35N + 0.2C
spitefulness = 0.55N + 0.45(1 − A)
```

`decideRefuse` 用这些倾向计算拒绝概率；`social_drive` 用记仇倾向决定是否发起闲话。

**在实验中的作用**

- 把人口统计条件化为异质决策倾向，是微观多样性的第二来源（第一来源是 BDIE 状态）。
- 记仇倾向让负面情感可累积、可定向。

**证据**

- 拒绝约 1.3 次/天，且拒绝率与性格显著相关。
- 闲话对象集中于 `dislike` 高的边，而非随机。

## 4. 结果解释：现象由什么机制生成

数字只是结果。本节说明每个现象**由哪个机制生成**——这也是本实验区别于"调出一个好看指标"的地方。

### 4.1 为什么回礼是延迟的（~17 slots）

```text
窗口基带（按类型）: instrumental 9–21 · 表达性≥0.8 ≥45 · 日常/邻里 ≤18
窗口调制（按关系/地位/现金）: 亲密≥65 ×0.9 · 亲密<30 ×1.25
```

真正产生"延迟"的是 `repay_drive.ts` 的尝试概率，而非窗口本身：

- `minElapsedFraction = 0.35`：窗口前 35% 内尝试概率被压到 `p ≈ 0.02`，几乎不提前还。
- 之后随剩余时段抬升：剩 >6 → `0.10 + 0.24·urgency`；剩 ≤3 → `0.42 + 0.32·urgency`；到期 → `0.70 + 0.20·urgency`。
- 再乘三个现实因子：经济承受力、关系亲密度（kin ×1.2 / friend ×1.1 / neighbor ×1.05）、身份容量（高地位 +1 笔，现金充裕再 +1/+2）。

所以 17 slots ≈ 窗口长度 × 期望等待位置，是**参数设计出的时间性**，不是事后拟合。E2（关互惠规则）后延迟趋近 0，反证成立。

> **理论对应**：阎云翔强调"人情是一笔不能立刻结清的账"。若把回礼概率设为恒定即时响应，人情就退化成转账；只有让"越早还越不像人情"成为可计算约束，延迟才会涌现而非被硬编码。

### 4.2 为什么是"互惠中态"而不是全还或全崩

同一个函数里并存两股力：

| 力    | 参数                              | 效果                     |
| ---- | ------------------------------- | ---------------------- |
| 临窗紧迫 | 剩 ≤3 slot 时 `p ≥ 0.42`          | 多数债务被拉回 → 互惠率 0.90     |
| 粘性放弃 | `abandonRate = 0.16`，一次性掷骰后不再尝试 | 少数永久违约 → default 0.022 |

放弃率还被三类条件修正：高地位 `×0.55`（面子要求最终还）、尽责性 `×(1.15 − 0.3C)`、现金 < 收入 8% `+0.08`（封顶 0.32）。于是违约不是随机噪声，而是**有社会梯度的道德失误**：干部 0、体力/服务 0.14。

> **理论对应**：书中的"欠情"不是债务合同，而是可被道德评价的状态。多数人受临窗压力归还（规范有效），少数人发生粘性放弃（规范被违反但可承受），二者共存才叫"中态"。

### 4.3 为什么"向上送"不会产生违约

`resolveReplyPolicy` 对这类礼物直接短路：

- `relationAxis ∈ {vertical_up, vertical_down}` → `replyRequired=false`、`initialStatus="closed"`、`recordDebt=false`；
- 准纵向（`isQuasiVerticalUp`：声望差 ≥18，或高地位收礼人 + 亲密 <45 且非亲属/朋友）→ 同样 closed。

结果：进贡进入"礼单"但不进入"债"——收礼人照拿 prestige，送礼人得到的是 face。

**因此干部组 defaults=0 的真实含义是**：进贡本就不在违约口径内，且高地位者放弃率还有 0.55 折。这两点共同维持"收礼多、面子不崩"的 H3 格局，而**不是**说干部道德更高。

> **理论对应**：阎云翔区分"横向互惠"与"纵向馈赠"：前者要还，后者是地位的确认。把二者放进同一个回礼窗口，必然出现"干部收礼越多、面子越崩"的假象。W6/R28 豁免正是对这一区分的编码。

### 4.4 为什么是"位→礼"而不是"钱→礼"

目标选择 `pairScore` 里，两种拉力用了不同的函数形状：

```text
prestigePull = prestige × 0.15 + face × 0.08        // 线性
wealthPull   = log10(1 + cash + deposit) × 4 × 0.5  // 对数压缩
```

声望差 30 分带来 4.5 分拉力；财富差 10 倍只带来约 2 分。**"线性 vs 对数"就是 0.575 与 0.109 的来源。**

正反馈放大差距：收礼 → `prestigeGain = 1.5 + value×0.005×expressive + √value×0.02` → 声望更高 → 更容易被选为目标。
负反馈防止赢者通吃：`1/cohort^0.12` 批次折减、每 slot 事件上限、`cash×0.5` 单笔上限。
两者平衡的结果是 gini 0.16、Top10 占 27% 的"中度集中分层村庄"。

> **理论对应**：礼物既是经济交换也是声望竞争。只让财富驱动目标选择，得到的是市场；让声望驱动、财富只做对数修正，得到的才是"争面子"的村庄。

### 4.5 分层与情绪的双向链条

四条链互相咬合，形成环而不是单向因果：

1. **情绪 → 网络**：`emotionDrive` 中 mood/energy 权重为正、stress 为负，且 `stress ≥ 0.65` 时整体 `×0.35` → 高压者不发起社交 → 关系边不增长 → 收礼机会变少。
2. **职业 → 现金 → 回礼能力**：`dailyLivingCost` 按职业与地位定价；`economyAffordFactor` 决定回礼概率（充足 ×1.15，贫困 ×0.25）→ 穷人更易违约。
3. **违约 → 关系**：`applyDefaultSocialEffects` 按 severity 扣 trust/affection，并写公共记忆 → 后续社交与送礼机会进一步减少。
4. **收礼 → 地位 → 收礼**：prestige/face 上升 → `pairScore` 拉力上升 → 收礼额上升。

于是 `income↔face 0.69`、`income↔prestige 0.688`、`face↔prestige 0.913`、`mood↔stress −0.817` 都是这个环在横截面上的投影。**情绪与性格因此不是分层的结果，而是分层的输入端之一。**

> **理论对应**：书中的分层不是"有人天生地位高"，而是在随礼—收礼—还礼的往复中逐步累积出来的。系统里没有预设等级，只有边权重与一次次结算；分层是这些微观往来在 365 天后的统计残影。

### 4.6 现象—机制对照

| 现象      | 生成机制                  | 关键参数                                     | 代码                                             |
| ------- | --------------------- | ---------------------------------------- | ---------------------------------------------- |
| 延迟互惠    | 窗口前段概率压制 + 临窗抬升       | `minElapsedFraction=0.35`                | `event/repay_drive.ts`                         |
| 互惠中态    | 临窗紧迫 vs 粘性放弃          | `abandonRate=0.16`、`statusDiscount=0.55` | `event/repay_drive.ts`                         |
| 纵向不对称   | 纵向/准纵向 → 不进债窗         | 声望差 ≥18、亲密 <45                           | `gift/norms.ts`                                |

## 5. 消融反证：组件是否真的在干活

| 消融          | 预期变化                  | 说明的结论       |
| ----------- | --------------------- | ----------- |
| **A2 无认知树** | 行为变随机；地位差异下礼物单向流动显著增强 | 主观记忆维持互惠对称性 |
| A1 无 BDIE   | 社交发起 / 拒绝 / 回礼紧迫度"变平" | 状态驱动决策多样性   |
| A3 无限资金     | 礼期望膨胀、分层扭曲            | 经济约束是分层前提   |
| E1 关礼单记忆    | 无法跨事件累计人情，重复送礼与关系判断变弱 | 礼物记忆的必要性    |
| E2 关互惠规则    | 违约↑、互惠↓、延迟趋近 0        | 规则承诺与时间性    |
| E3 仅横向      | 进贡不再单向，H3 失效          | 纵向轴的因果作用    |
| E4 无场合规范    | "喜事难拒"消失，拒绝率异常        | 场合规范的独立贡献   |

**读法**：消融不是凑材料，而是回答——"多智能体多出来的那些模块，是不是真的在干活？"每一行都对应一个可观测指标，而不是主观判断。

## 6. 复现方法

```powershell
# 主跑（100 人 × 365 天 live）
$env:P5_LLM_MODE = "live"
npm run sim:run:live100

# 复跑（seed=42）
npm run sim:run:final365

# 消融 / 对照
npm run sim:ablation

npm run analyze:final365
```

回放任意一次 run：

```powershell
$env:RUN_ID = "<runId>"
npm run frontend:export
npm run frontend:serve   # http://127.0.0.1:5177/
```

## 7. 局限

1. **宏观—微观解离风险**：群体指标像民族志，不证明每个 Agent 的心理过程像人。
2. **人类数据对齐仍浅**：尚未做问卷边际 / 分布级 KS 对照。
3. **时序简化**：同步 slot ≠ 真实 burstiness。
4. **模型敏感性**：主结果基于单一 live 模型（DeepSeek）；复跑中 prestige 相关从 0.51 降到 0.27，说明该指标对模型与随机性较敏感，但排序结论稳定。
5. **伦理边界**：机制探索与教学演示，不替代田野因果识别。
